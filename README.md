🎮 Projeto Jokenpo

Ah, esse todo mundo conhece! O famoso Pedra, Papel e Tesoura, um dos jogos mais populares e muito fácil de jogar. Aqui não tem segredo: a lógica é simples e direta.

Se eu escolher pedra e o robô escolher pedra, dá empate 🤝

Se eu escolher pedra e o robô escolher tesoura, eu ganho 🏆

Se eu escolher papel e o robô escolher pedra, eu ganho 🏆

Se eu escolher tesoura e o robô escolher papel, eu ganho 🏆

Se não for nenhum desses cenários, eu perco para o robô 🤖

Esse projeto foi desenvolvido durante as aulas de JavaScript no DevClub, com o mestre Rodolfo Mori, que sempre nos incentiva a diferenciar nossos projetos, mudando detalhes aqui e ali para que nenhum projeto fique igual ao outro. A ideia é fazer com que um recrutador olhe e pense:

“Nossa, esse projeto ficou bem diferenciado!”

O Rodolfo sempre fala que programador que não sabe pesquisar, fica para trás, e isso ficou muito claro nesse projeto. Desde o início, eu já pensava em como deixá-lo diferente dos demais. Pesquisei bastante e decidi criar os três botões em formato de pedra, usando um decágono (10 lados), além de aplicar um estilo gamer para deixar o visual mais marcante.

🧠 Lógica e Funcionalidades

No projeto, foram utilizadas:

Uma função para capturar a escolha do jogador

Uma função para gerar a escolha aleatória do robô

Uma função responsável por decidir o vencedor, utilizando if, else if e else

Dentro das condições, utilizei operadores como:

=== (igualdade estrita)

&& (E lógico)

|| (OU lógico)

Também foram usadas funções anônimas (arrow functions) junto com o addEventListener, permitindo capturar os eventos de clique nos botões de forma clara e organizada.

Além disso, o projeto foi adaptado para dispositivos móveis, utilizando responsividade, garantindo uma boa experiência tanto no desktop quanto no mobile 📱💻.

Esse projeto representa uma grande conquista na minha jornada como programador. Fico muito feliz por conseguir entender toda a lógica do jogo, aplicar conceitos de JavaScript e ainda usar a criatividade para criar algo diferente. Pesquisar, testar e errar fez parte de todo o processo — e isso faz toda a diferença na evolução.
